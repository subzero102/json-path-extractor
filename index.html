Extract JSON Data with JSONPath

JSONPath makes it easy to extract specific values from deeply nested JSON. Start with the root symbol $ and use property names, array indexes, wildcards, recursive descent, and filters to select the data you need.

Example JSON

{
  "users": [
    {
      "name": "John",
      "age": 30,
      "email": "john@example.com"
    },
    {
      "name": "Sarah",
      "age": 25,
      "email": "sarah@example.com"
    }
  ]
}

Extract all user names

Use the following JSONPath expression:

$.users[*].name

The result is:

["John", "Sarah"]

You can use the JSONPath Extractor above to experiment with this expression and test it against your own JSON documents.

JSONPath Syntax and Operators

Learn the most commonly used JSONPath operators for navigating JSON, selecting arrays, matching properties, recursively searching nested data, and filtering results.

Common JSONPath Operators and Expressions
Operator Name Description Example Expression
$ Root Object Represents the root object or array from which all JSONPath expressions originate. $ or $.store.book
@ Current Node Refers to the current element being processed in a filter predicate or array iterator. [?(@.price < 20)]
.. Recursive Descent Deep scan selector that traverses recursively across all child and descendant levels to find matching keys. $..author or $..price
[*] Array Wildcard Matches all elements contained in an array, or all property values within an object. $.store.book[*]
[?()] Filter Expression Applies a logical boolean expression to filter items within an array or collection. $.store.book[?(@.category == 'fiction')]
* Wildcard Matches any property name or value at the current hierarchical level. $.store.*
['key'] Bracket Notation Selects a property by string key; essential for keys containing spaces, hyphens, or special characters. $['store']['bicycle']
[start:end:step] Array Slice Extracts a slice of array elements using start, end, and optional step indices. $.store.book[0:2]

JSONPath Root Operator

The $ symbol represents the root of a JSON document. For example, $.user.name selects the name property inside the root-level user object.

JSONPath Wildcard

The * wildcard matches properties or array elements at the current level. For example, $.users[*].name extracts the name property from every item in the users array.

JSONPath Recursive Descent

The .. operator searches recursively through nested objects and arrays. For example, $..email can locate email properties regardless of their depth within the JSON document.

JSONPath Filter Expressions

Filter expressions allow you to select array elements based on conditions. For example, $.products[?(@.price < 100)] selects products whose price is less than 100.

What is JSONPath?

JSONPath is a query language for navigating and extracting data from JSON documents. It provides expressions for selecting properties, array elements, nested objects, and values from complex JSON structures.

JSONPath is often compared to XPath for XML. Developers commonly use it when working with REST API responses, configuration files, application logs, automated tests, and other structured JSON data.

Instead of manually traversing a JSON object in code, a JSONPath expression lets you describe exactly which data you want to retrieve.
